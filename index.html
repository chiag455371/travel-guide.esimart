❓ eSIM 常見問題

什麼是 eSIM？和實體 SIM 卡有什麼不同？

eSIM 是內建於手機中的數位 SIM 卡，無需實體卡即可啟用行動數據方案。只需掃描 QR Code 即可完成安裝，支援 4G/LTE 高速網路，落地立即使用。

eSIM 安装需要技術能力嗎？

完全不需要！收到 QR Code 後，打開手機設定 → 行動數據 → 新增 eSIM，掃描 QR Code 即可完成。整个过程約 2–3 分鐘。

我的手機支援 eSIM 嗎？

iPhone XS 及以上、Samsung S20 及以上、Google Pixel 3 及以上均支援。請確認您的手機型號是否在支援列表中。

eSIM 和 Wi-Fi 有什麼差別？

公共 Wi-Fi 訊號不穩、安全性低、需要逐處連接。eSIM 提供穩定的 4G/LTE 網路，無論在哪裡都能即時上網，更安全也更可靠。
